# Loader

A web-based loader animation project designed to display loading effects with a clean and modern user interface.

🔗 **Live Demo:** https://akashmadavi2001.github.io/Loader/

## Features
- Smooth loading animation
- Simple and clean design
- Lightweight and easy to use
- Hosted using GitHub Pages

## Technologies Used
- HTML
- CSS
- JavaScript

Visit the live demo to see the loader animation in action.
